# Cart UI Fragment (`cart-ui`)

> **Micro-Frontend (MFE) Shopping Cart Fragment powered by commercetools (`cart-service`)**

`cart-ui` is a standalone, embeddable frontend fragment providing the shopping cart and checkout review experience.

---

## 🎯 Features

1. **commercetools Cart State:** Line item quantities, real-time price totals, and currency handling.
2. **Kitchen Fitment Readiness Alert:** Highlights verified countertop clearance vs unverified appliances to prevent post-delivery returns.
3. **Responsive Order Summary:** Tax estimation, white-glove delivery, and checkout trigger.

---

## 🚀 Development

```bash
npm install
npm run dev     # Runs dev server on port 5176
npm run build   # Compiles standalone MFE bundle
```
